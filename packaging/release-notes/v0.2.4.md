**TL;DR:** Omafeed 0.2.4 adds content filters that hide articles by keyword or regex, and a context menu on sidebar feeds, folders and views. It closes a hole that let sites on the internet make Omafeed request addresses on your local network, and fixes refresh, import and undo races. The library moves to schema version 4, so back it up if you may need to go back to 0.2.3.

**Download:** [Arch Linux recipe](https://github.com/pch/omafeed/releases/download/v0.2.4/PKGBUILD) (`makepkg -si`) · Linux archive ([x86_64](https://github.com/pch/omafeed/releases/download/v0.2.4/omafeed-0.2.4-x86_64-linux.tar.gz), [ARM](https://github.com/pch/omafeed/releases/download/v0.2.4/omafeed-0.2.4-aarch64-linux.tar.gz)) · On Omarchy: `omarchy pkg add omafeed`

## New

- **Content filters** ([#19](https://github.com/pch/omafeed/pull/19)). **Content filters…** in the menu hides articles whose title or preview matches a word or a `/regex/`, ignoring case unless a regex says `(?-i)`. Hidden articles leave lists, unread counts and "mark all read" alone, and starred articles are never hidden. The command line applies the same filters, though `omafeed article <id>` still opens a hidden article. Filters are kept in `settings.toml`.
- **A context menu in the sidebar** ([#30](https://github.com/pch/omafeed/pull/30)). Right-click a feed, folder or view, or press the Menu key or Shift+F10 on it. A feed's menu opens or copies its home page, copies its feed URL, marks it all read (undo with Ctrl+Z), and edits or removes it; a folder's marks it read and edits or removes it; a view's marks it read.

## Fixed

- **Refreshes no longer store a changed feed's old articles** ([#16](https://github.com/pch/omafeed/pull/16)). A refresh that finished after its feed's URL changed, or after the feed was removed or replaced, used to store the old feed's articles, validators, website, schedule or error, and could even attach them to a new feed that reused its ID.
- **Importing the same OPML file twice works** ([#17](https://github.com/pch/omafeed/pull/17)) when a folder name has spaces around it.
- **Read and star changes show at once and keep the newest** ([#18](https://github.com/pch/omafeed/pull/18)). Pressing S or M several times quickly toggles each time. Undoing "mark all read" marks unread only that batch, and a failed undo can be tried again. The read mark set on opening an article is undone on screen if saving it fails, and a slow database answer no longer overwrites a newer change.
- **Counts and the open article come from one snapshot** ([#20](https://github.com/pch/omafeed/pull/20)), even while another program changes the library. `omafeed unsubscribe` reports exactly what it deletes.

## Security

- **Sites can't lead Omafeed to your local network** ([#21](https://github.com/pch/omafeed/pull/21)). A site on the internet can no longer make Omafeed request `localhost`, loopback, private, link-local, CGNAT or IPv6 unique- and site-local addresses, whether by redirecting, advertising a feed during discovery, naming a website, or linking an icon. Feeds you enter yourself may still be local. Host names are not resolved for this check, and images in articles are loaded by WebKit without it.

## Upgrade notes

- **The library moves to schema version 4,** which adds feed revisions. It is upgraded the first time 0.2.4 opens it. Older versions then refuse it with "Database was created by a newer Omafeed version", so back up the data directory (`~/.local/share/omafeed`) first if you may need to go back.

## Requirements

Omafeed needs `gtk4`, `libadwaita` 1.6 or newer and `webkitgtk-6.0`. The x86_64 archive is built on Arch Linux; the ARM archive is built on Debian 13 and needs glibc 2.41 or newer.
