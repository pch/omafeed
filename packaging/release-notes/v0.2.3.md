**TL;DR:** Omafeed 0.2.3 brings back Omarchy theme following, which had silently stopped working in 0.2.1 and 0.2.2, and adds a Linux archive for ARM (aarch64).

**Download:** [Arch Linux recipe](https://github.com/pch/omafeed/releases/download/v0.2.3/PKGBUILD) (`makepkg -si`) · Linux archive ([x86_64](https://github.com/pch/omafeed/releases/download/v0.2.3/omafeed-0.2.3-x86_64-linux.tar.gz), [ARM](https://github.com/pch/omafeed/releases/download/v0.2.3/omafeed-0.2.3-aarch64-linux.tar.gz))

## New

- **A Linux archive for ARM.** `omafeed-0.2.3-aarch64-linux.tar.gz` is built on Debian 13. Extract the archive for your architecture (`uname -m`) into `~/.local` as described in the README.

## Fixed

- **Omarchy colors apply again.** Since the library update in 0.2.1, Omafeed could not read Omarchy's `colors.toml`, so it fell back to its built-in dark palette whatever your theme was. The file is read correctly again.

## Requirements

Omafeed needs `gtk4`, `libadwaita` 1.6 or newer and `webkitgtk-6.0`. The x86_64 archive is built on Arch Linux; the ARM archive is built on Debian 13 and needs glibc 2.41 or newer.
