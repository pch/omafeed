**TL;DR:** Omafeed 0.2.2 updates dependencies to pick up fixes for published security advisories, including the HTML sanitizer and TLS libraries, and fixes the build failing outside the UTC time zone.

**Download:** [Arch Linux recipe](https://github.com/pch/omafeed/releases/download/v0.2.2/PKGBUILD) (`makepkg -si`) · Linux archive ([x86_64](https://github.com/pch/omafeed/releases/download/v0.2.2/omafeed-0.2.2-x86_64-linux.tar.gz))

## Security

- **Dependencies updated for security advisories** ([#14](https://github.com/pch/omafeed/pull/14)). ammonia (the article HTML sanitizer) 4.2.4 fixes RUSTSEC-2026-0373, rustls 0.23.46 fixes RUSTSEC-2026-0346 through -0349, rustls-webpki 0.103.16 fixes RUSTSEC-2026-0382, and webpki-roots 1.0.11 fixes RUSTSEC-2026-0381. Other routine updates are included ([#10](https://github.com/pch/omafeed/pull/10)).

## Fixed

- **Building from source works in any time zone** ([#13](https://github.com/pch/omafeed/pull/13), issue [#12](https://github.com/pch/omafeed/issues/12)). A test assumed the local date of timestamp 0 was 1970-01-01, which holds only at UTC and east of it, so `cargo test` and the Arch package's `makepkg` check failed in time zones west of UTC.

## Thanks

Thanks to [@PDXPuma](https://github.com/PDXPuma) for reporting the time zone failure and fixing it ([#13](https://github.com/pch/omafeed/pull/13)).

## Requirements

Omafeed needs `gtk4`, `libadwaita` 1.6 or newer and `webkitgtk-6.0`. The x86_64 archive is built on Arch Linux.
