**TL;DR:** Omafeed 0.1.1 polishes reading: a redesigned article list, the feed's icon and name above each article, article text in your desktop font, and cleaner previews. Your library is upgraded the first time 0.1.1 opens it.

**Download:** [Arch Linux recipe](https://github.com/pch/omafeed/releases/download/v0.1.1/PKGBUILD) (`makepkg -si`) · Linux archive ([x86_64](https://github.com/pch/omafeed/releases/download/v0.1.1/omafeed-0.1.1-x86_64-linux.tar.gz))

## Improved

- **A redesigned article list.** Titles lead, with a small feed and date line above. Unread articles get an accent dot and a bold title, and stars show as an icon. Dates are relative (time, Yesterday, weekday, then month and day, with the year for older items). The feed name is hidden inside a single feed, and a list that fits one page shows its article count instead of a page range.
- **The reader opens with the source.** The feed's icon and name, linked to its website, appear above the article, with the date in the byline. The icon comes from the local cache, so it also shows offline and with remote images off.
- **Article text uses your desktop font.** Body text used Georgia, which is rarely installed on Linux, so it fell back to a lookalike that clashed with the sans-serif title.

## Fixed

- **Previews and search text no longer put a space before punctuation after a link** (for example "Spotify , Apple"). Stored articles are re-read on upgrade, so existing previews and the search index are corrected too.
- **The reader toolbar icons match your icon theme.** The read/unread and open-original buttons could show full-color icons, such as a blue envelope under Yaru, on themes other than Breeze.

## Upgrade notes

- **The library moves to schema version 2.** It is upgraded the first time 0.1.1 opens it. Older versions then refuse it with "Database was created by a newer Omafeed version", so back up the data directory (`~/.local/share/omafeed`) first if you may need to go back to 0.1.0.

## Requirements

Omafeed needs `gtk4`, `libadwaita` 1.6 or newer and `webkitgtk-6.0`. The x86_64 archive is built on Arch Linux.
